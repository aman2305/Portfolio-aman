# Aman Lakhera — Personal Portfolio

A **Mojave-themed professional portfolio** website built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

## 🚀 Live Preview
Deploy on GitHub Pages → `https://aman2305.github.io/portfolio`

## 📁 Files
```
portfolio/
├── index.html    ← Main HTML structure
├── style.css     ← Mojave dark theme styles
├── script.js     ← Animations & interactions
└── README.md     ← This file
```

## ✨ Features
- **Mojave desert night-sky** theme — dark bg, burnt orange & gold accents
- Animated starfield canvas background
- Smooth scroll reveal animations
- Interactive 3D card tilt on hover
- Typing effect on hero section
- Scroll progress indicator
- Cursor glow effect (desktop)
- Fully responsive (mobile-first hamburger menu)
- Fast — no external JS libraries

## 🛠️ How to Upload on GitHub

### Option 1: GitHub Pages (Free Hosting)
1. Create a new repo: `aman2305/portfolio` (or any name)
2. Upload all 3 files: `index.html`, `style.css`, `script.js`
3. Go to **Settings → Pages → Source → main branch / root**
4. Your site will be live at `https://aman2305.github.io/portfolio`

### Option 2: Via Git CLI
```bash
git init
git add .
git commit -m "Add portfolio website"
git remote add origin https://github.com/aman2305/portfolio.git
git push -u origin main
```
